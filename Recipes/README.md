# Odin Recipes

A responsive recipe website built as part of [The Odin Project](https://www.theodinproject.com/) curriculum. 

##  Description

This is my very first complete web development project. The goal was to build a multi-page recipe website from scratch to practice the foundations of web development. It started as a pure HTML project and was later revisited to incorporate modern CSS techniques, including Flexbox and interactive hover states.

You can view the live project here: https://maria-papadopoulou.github.io/Recipes/

##  Skills & Technologies Used

* **HTML5:** Semantic markup, proper document structure, lists, and linking between pages.
* **CSS3:** 
  * **Flexbox:** Used for aligning the recipe cards in a responsive grid-like layout.
  * **CSS Transitions:** Added smooth hover effects and scaling animations to the recipe images (`transform: scale()`).
  * **Image Optimization:** Utilized `object-fit: cover` and `overflow: hidden` to create uniform, aesthetically pleasing image cards without distorting the original photos.
  * **Styling:** Custom fonts (Google Fonts), gradients, and box-shadows for a modern UI.
