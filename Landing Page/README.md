# Odin Landing Page

A responsive landing page built from scratch as part of [The Odin Project](https://www.theodinproject.com/) curriculum. 

## Description

This project focuses on translating a design mockup into a fully functional webpage. The primary goal was to master CSS Flexbox for element positioning and build a clean, modern layout featuring a header, a hero section, information cards, a testimonial quote, and a call-to-action banner.

## Skills & Technologies Used

* **HTML5:** Semantic structuring using tags like `<header>`, `<main>`, `<section>`, and `<footer>` for better accessibility and readability.
* **CSS3:** 
  * **Flexbox:** Extensive use of `display: flex`, `justify-content`, and `align-items` to create complex layouts, align navigation links, and evenly distribute information cards.
  * **Responsive Design:** Implemented `@media (max-width: 900px)` queries to ensure the hero section and call-to-action stack gracefully on mobile devices and smaller screens.
  * **Modern Layout Techniques:** Used `width: min(1100px, 100%)` for dynamic, self-adjusting containers that never break out of the screen.
  * **Styling:** Custom CSS buttons, hover effects, Google Fonts integration (Roboto), and clean geometric styling.
